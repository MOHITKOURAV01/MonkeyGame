# 🐵 Monkey Shooting Game :-

A fast-paced tap-to-shoot game where a monkey fires bullets at incoming trucks. Score points by hitting targets—misses reduce your score!

## 🎮 Gameplay

- Tap the screen to fire bullets.
- Trucks move upward on the road.
- Hitting a truck gives **+10 points**.
- Missing a shot gives **–10 points**.
- Aim carefully to maintain your score.

---

## Features

- Tap-to-shoot mechanics  
- Monkey, truck, bullet, and road PNG assets  
- Score system (+10 for hit, –10 for miss)  
- Vertical gameplay with 90° rotated background  
- Smooth performance on mobile
